## Retained alternative (not used by the site)

`a-few-things-lofi.mp3` is the earlier original instrumental composed and
synthesized for Jamie's portfolio. It uses no external recordings or
third-party samples.

The 16-bar, 76 BPM loop combines electric-piano-style major/ninth chords, muted
bass, a sparse melody, and swung drums. It is deliberately mixed quietly.

Its source is `scripts/render-lofi.py`. Regenerating this alternative requires
Python with NumPy and ffmpeg; deployment does not require either.

To replace it, update the local source URL in each page's `#site-music` audio
