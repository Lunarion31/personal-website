# Self-hosted fonts

Downloaded from Google Fonts on 2026-09-30. The files are unmodified WOFF2 Latin subsets from the official Google Fonts service.

- `barlow-condensed-latin-700.woff2`: Barlow Condensed, normal style, weight `700`. License: `Barlow-Condensed-OFL.txt`.
- `manrope-latin-variable.woff2`: Manrope, normal style, variable weight descriptor `400 700`. License: `Manrope-OFL.txt`.
- `instrument-serif-latin-400.woff2`: Instrument Serif, normal style, weight `400`. License: `Instrument-Serif-OFL.txt`.
- `instrument-serif-latin-400-italic.woff2`: Instrument Serif, italic style, weight `400`. License: `Instrument-Serif-OFL.txt`.
- `bodoni-moda-latin-600.woff2`: Bodoni Moda, normal style, weight `600`. License: `Bodoni-Moda-OFL.txt`.
- `bodoni-moda-latin-600-italic.woff2`: Bodoni Moda, italic style, weight `600`. License: `Bodoni-Moda-OFL.txt`.
- `dm-serif-display-latin-400.woff2`: DM Serif Display, normal style, weight `400`. License: `DM-Serif-Display-OFL.txt`. Used by the typography comparison page only.
- `newsreader-latin-600.woff2`: Newsreader, normal style, weight `600`. License: `Newsreader-OFL.txt`. Used by the typography comparison page only.

Bodoni Moda is the current display face, using its real semibold weight and italic rather than simulated strokes or slants. Manrope is used for body text; Barlow Condensed is used for navigation and editorial labels. Instrument Serif is retained as an unused asset from the earlier design.

Use `font-display: swap` when declaring these fonts.
